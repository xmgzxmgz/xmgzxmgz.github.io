机器学习入门：用 SVM 分类鸢尾花

2025-10-17 · Python Sklearn 机器学习 · 约 3 分钟

支持向量机（SVM）是经典的分类算法。本文用 Iris 数据集演示 SVM 的完整流程：特征选择、模型训练、超参数调优、混淆矩阵分析。

🧮 什么是 SVM？

SVM 的核心思想是找到一个最优超平面，使得不同类别的样本到超平面的间隔最大化。

对于非线性可分的数据，SVM 使用核函数将数据映射到高维空间，使其线性可分。

🔧 完整代码

from sklearn import datasets
from sklearn.model_selection import train_test_split
from sklearn.svm import SVC
from sklearn.metrics import classification_report, confusion_matrix
import numpy as np

# 加载数据
iris = datasets.load_iris()
X = iris.data[:, :2]  # 只用前两个特征（便于可视化）
y = iris.target

# 划分训练集和测试集
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42, stratify=y
)

# 训练 SVM（不同 gamma 值）
for gamma in [0.1, 1, 10]:
    svm = SVC(kernel='rbf', gamma=gamma, C=1.0)
    svm.fit(X_train, y_train)
    accuracy = svm.score(X_test, y_test)
    print(f'gamma={gamma}: 准确率 = {accuracy:.2%}')

# 最佳模型的混淆矩阵
best_svm = SVC(kernel='rbf', gamma=1, C=1.0)
best_svm.fit(X_train, y_train)
y_pred = best_svm.predict(X_test)
print(confusion_matrix(y_test, y_pred))

📊 实验结果

gamma准确率说明
0.1~75%欠拟合，决策边界太简单
1.0~80%较好平衡
10~70%过拟合，决策边界太复杂

💡 关键收获

  • gamma 控制复杂度：gamma 越大，决策边界越复杂，越容易过拟合
  • 特征选择很重要：只用 2 个特征 vs 4 个特征，准确率差距很大
  • 混淆矩阵比准确率更有用：能看清楚哪些类别被混淆了
  • stratify 参数：划分数据集时保持类别比例一致
