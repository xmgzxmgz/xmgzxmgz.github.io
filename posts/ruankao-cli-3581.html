把 3581 道题装进终端

2026-08-23 · Python 学习工具 · 约 2 分钟

备考软考高项，网上的刷题平台都太吵了。于是写了个终端刷题器：零依赖、离线、外观像在跑单元测试。

备考信息系统项目管理师（高项）的时候，市面上的刷题工具都有点吵：要登录、要开网页、弹窗、广告。而我每天盯着终端的时间最长——那就写一个终端刷题器。

⌨️ 两个形态

  • 纯键盘 CLI：零依赖，只用 Python 3 标准库，不联网、无弹窗
  • 终端 TUI（默认）：在命令行里用鼠标点选项作答，外观仍然像在跑测试或看构建日志——在工位上用也不突兀

📚 题库功能

python drill.py                  # 随机练全部 3581 题
python drill.py --cat 信息化发展  # 按 144 个章节分类练
python drill.py --wrong          # 只复习错题本，答对自动移出
python drill.py --mock           # 模拟考试（75 题 / 150 分钟）
python drill.py --paper 2023上   # 练某年真题

错题本的设计是答对自动移出——错题本的长度就是你距离通过的剩余工作量，让它只增不减没有意义。

💡 做工具的一点点心得

这个工具没有任何「技术含量」：标准库、离线题库、几个循环。但它每天真的被使用，考试也过了。能陪伴你度过一个真实目标的小工具，比仓库里十个炫技项目更有价值。
