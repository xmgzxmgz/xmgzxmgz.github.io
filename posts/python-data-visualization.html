Python 数据可视化：5 种图表玩转 Iris 数据集

2025-10-17 · Python Matplotlib 数据可视化 · 约 3 分钟

Iris（鸢尾花）数据集是机器学习的 "Hello World"。本文用 5 种图表从不同角度探索这个经典数据集。

📊 5 种图表

  1. 散点图 — 花瓣长度 vs 花瓣宽度，按品种着色
  2. 箱线图 — 各品种花萼宽度的分布
  3. 柱状图 + 饼图 — 各品种数量占比
  4. 散点矩阵 — 所有特征两两对比
  5. 直方图 — 花瓣长度的分布

任务 1：散点图

import pandas as pd
import matplotlib.pyplot as plt
from sklearn.datasets import load_iris

iris = load_iris()
df = pd.DataFrame(iris.data, columns=iris.feature_names)
df['species'] = iris.target_names[iris.target]

# 散点图：花瓣长度 vs 宽度
fig, ax = plt.subplots(figsize=(8, 6))
for species in df['species'].unique():
    subset = df[df['species'] == species]
    ax.scatter(subset['petal length (cm)'], subset['petal width (cm)'],
               label=species, alpha=0.7, s=50)
ax.set_xlabel('花瓣长度 (cm)')
ax.set_ylabel('花瓣宽度 (cm)')
ax.set_title('Iris 数据集：花瓣长度 vs 宽度')
ax.legend()
plt.tight_layout()
plt.savefig('scatter_petal.png', dpi=150)

任务 4：散点矩阵

散点矩阵可以一次性看到所有特征之间的关系：

import seaborn as sns

sns.pairplot(df, hue='species', diag_kind='kde',
             plot_kws={'alpha': 0.6, 's': 30})
plt.suptitle('Iris 特征散点矩阵', y=1.02)
plt.savefig('scatter_matrix.png', dpi=150)

💡 发现

  • Setosa 品种在所有特征上都与另外两个品种明显分离
  • Versicolor 和 Virginica 在花瓣特征上有部分重叠
  • 花瓣长度和花瓣宽度的相关性最强（r ≈ 0.96）
  • 散点矩阵是快速了解数据集的最佳工具
