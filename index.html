03关于

About

写代码开头是为了把重复的活儿干掉。
后来发现真正上瘾的，是「想到的」变成「能跑起来的」那一下。

现在主要做两类事。一类是 AI Agent 和围绕它的工具链——消息路由、记忆、模型接入、协议转换；另一类是别人不太愿意碰的脏活——批量导出、格式转换、硬件对接。

习惯用 Python 起步试错，最后用 Rust / Swift / C# 或 Go 落成一个能双击运行的东西。原型要快，成品要稳，这两件事不该用同一套标准要求。

不太喜欢过度设计。两百行能解决的不引框架，本地能跑的不上云，能读懂的比能跑分的更重要。这个站也是这样：手写的 HTML + CSS，没有构建步骤，字体用系统自带的——你先看到内容，再看到装饰。
